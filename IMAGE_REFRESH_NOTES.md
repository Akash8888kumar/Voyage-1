# Voyage 1 image refresh

Updated the 9 destination pages to use selected existing WebP assets that were previously not referenced by the site.

For each destination page, the refresh updates:
- local partner / intro image
- 7 destination-card images
- 1 featured destination image
- 2 smaller featured destination images

Hero images were left unchanged because they were already appropriate and actively used.

New URL-safe copies live under `assets/images/` and are referenced by page-specific CSS overrides appended to each destination HTML file.
